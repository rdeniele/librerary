# Roadmap

1. Finish Phase 0: actual REA evidence if available, bounded workflow observation, engine spikes and dependency/license inventory. Current research is partial.
2. Validate launcher foundation: native compile/launch, persistence/close/export, keyboard/accessibility, browser/native distinction and performance baseline.
3. Complete Phase 1 module foundation: local manifests, version/capability validation, installation/update/rollback design and safe project preservation.
4. Select an office engine through fixtures; build genuine Writer interoperability, then Sheets, Slides and PDF.
5. Establish shared design/raster/vector foundations.
6. Build and validate Studio MVP, then advanced workflows/plugins.
7. Add Video/Motion, Audio/Publish and optional 3D incrementally.
8. Harden security, packaging, accessibility, performance and release compliance.

Current priority is REA/WPS investigation; defer new application features until that checkpoint. Delivered source includes the Apple-inspired launcher, text projects and verified offline Writer templates. The remaining phases are not implemented; no release dates are promised. Detailed acceptance criteria remain in [the master brief](knowledge/MASTER_PROMPT.md).
