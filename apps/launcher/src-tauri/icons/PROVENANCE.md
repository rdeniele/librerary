# Icon provenance

All current icons in this directory were converted by the Tauri CLI from `assets/brand/librerary-icon.png`, the original glass document-stack identity generated with the built-in Imagegen tool on 2026-10-17. The exact prompt and provenance are preserved in `assets/brand/`. No competitor artwork was supplied. Reproduce from the repository root:

```powershell
node node_modules/@tauri-apps/cli/tauri.js icon assets/brand/librerary-icon.png --output apps/launcher/src-tauri/icons
```
