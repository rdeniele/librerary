# Librerary
<!-- impeccable:product-schema 1 -->

## Platform
web

Desktop application for Windows 10/11 x64, rendered through a Tauri webview. Linux/macOS are future targets.

## Stack
Delegated by the master brief: evaluate technology and make reversible decisions autonomously. Initial foundation: Tauri 2, Rust, React and TypeScript. No third-party editing engine selected yet.

## Users
Beginners and professional creators who need free productivity and creative tools offline.

## Product Purpose
An independently installable modular productivity and creative suite. See knowledge/PRODUCT.md and knowledge/MASTER_PROMPT.md for requirements, not implemented-feature claims.

## Operating Context
Local desktop files, keyboard workflows, independently loaded modules. No forced accounts or cloud dependency.

## Capabilities and Constraints
No AI integration, paid gates, subscriptions, ads, or artificial export limits. Preserve user files and project data. Heavy engines load only when needed. Measured performance must accompany performance claims.

## Brand Commitments
Librerary. Create freely. Work professionally. Easy to start. Powerful to master.
User selected a compact utility launcher focused on speed (2026-10-16).
User requested an Apple-inspired redesign (2026-10-17): system/SF Pro typography on Apple devices, generous whitespace, rounded controls, subtle borders and functional translucent navigation. Original blue glass document-stack identity. All existing workflows and logic must be preserved. Windows uses its native system font; SF Pro is not redistributed.

## Evidence on Hand
Complete original brief in knowledge/MASTER_PROMPT.md; research reports in docs/research. No shipped module or measured baseline at project inception.

## Product Principles
- Make common actions fast and keyboard accessible.
- Keep unavailable features explicitly unavailable.
- Preserve data before expanding capabilities.
- Keep engine and module boundaries independent.
